# 🌀 whimsy

> 一些奇思妙想。随手记下，慢慢长大。

这里收集我日常冒出来的小点子：有的只是洗澡时的一句话，有的会长成一个小工具，还有的可能永远躺在角落里落灰。先记下来，再决定要不要认真。

## 目录结构

```text
whimsy/
├── README.md                    # 项目说明 + 想法索引
├── ideas/                       # 所有想法，一条一个 Markdown 文件
│   ├── _template.md             # 新想法模板
│   └── 2026-10-20-example-*.md  # 示例想法（可删）
└── scripts/
    └── new_idea.py              # 一条命令新建想法，并自动刷新索引
```

## 怎么记一条新想法

**方式一：用脚本（推荐）**

```bash
python scripts/new_idea.py "会自己长大的桌面植物" --tags 桌面,养成
```

脚本会按模板生成 `ideas/2026-10-20-会自己长大的桌面植物.md`，并自动刷新本页的「想法总览」。

| 参数 | 说明 |
| --- | --- |
| `--tags a,b` | 标签，顿号或逗号分隔均可 |
| `--status seed` | 状态，默认 `seed`（见下方说明） |
| `--date 2026-10-20` | 指定记录日期，默认为今天 |
| `--slug my-idea` | 指定文件名后缀，默认由标题生成 |
| `--no-index` | 创建后不自动刷新索引 |
| `--reindex` | 只刷新 README 索引，不新建文件 |

**方式二：手动来**

复制 `ideas/_template.md`，把文件名改成 `YYYY-MM-DD-简短标题.md`，然后尽情写。

## 一条想法长什么样

每个文件开头有一段 front matter：

```markdown
---
title: "会自己长大的桌面植物"
date: 2026-10-20
tags: [桌面, 养成]
status: seed
spark: 一盆桌面植物，随着你完成待办而慢慢长大。
---
```

正文不强制结构，但建议至少回答三个问题：

1. **它是什么？** 一句话说清楚。
2. **为什么让我心动？** 它哪里好玩、解决了什么小问题。
3. **下一步能做什么？** 哪怕只是“先去搜一下有没有人做过”。

## 状态

| 状态 | 含义 |
| --- | --- |
| 🌱 `seed` | 刚冒出来，只有一句话 |
| 🔭 `exploring` | 值得花点时间调研 |
| 🛠️ `building` | 正在动手实现 |
| ✅ `done` | 已经变成现实 |
| 🧊 `shelved` | 先放一放，不删除 |
